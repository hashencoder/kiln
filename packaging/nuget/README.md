# ServNook (portable)

ServNook is a free, open-source local web stack for Windows: Apache, the latest PHP, MariaDB, phpMyAdmin and Node.js in one portable folder, with one control panel.

This package contains the portable app in `tools\ServNook`. Copy that folder to a short path without spaces (for example `C:\ServNook`) and run `ServNook.exe`.

Easier ways to install:

- **Installer:** https://github.com/hashencoder/servnook/releases/latest
- **winget:** `winget install ServNook`
- **Scoop:** `scoop bucket add servnook https://github.com/hashencoder/servnook` then `scoop install servnook`

Source, documentation and issues: https://github.com/hashencoder/servnook (MIT licence).
